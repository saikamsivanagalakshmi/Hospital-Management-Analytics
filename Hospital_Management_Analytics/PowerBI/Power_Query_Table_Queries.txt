Create a Text parameter named pWorkbookPath containing the full local path to the workbook. Then create one blank query per table and paste the matching expression below into Advanced Editor. These queries promote headers and assign expected types. Add Trim/Clean using the function template if needed.

===== QUERY: Departments =====
let
    Source = Excel.Workbook(File.Contents(pWorkbookPath), null, true),
    T = Source{[Item="Departments",Kind="Sheet"]}[Data],
    H = Table.PromoteHeaders(T,[PromoteAllScalars=true]),
    C = Table.TransformColumnTypes(H,{{"Department_ID", type text},{"Department_Name", type text},{"Department_Type", type text},{"Bed_Capacity", Int64.Type}})
in C
